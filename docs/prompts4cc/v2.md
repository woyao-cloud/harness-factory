  2. Token 预算管理 — ContextManager._check_budget()

  位置： context_manager/manager.py:63-72

  class ManagerConfig:
      total_budget: int = 64000          # L1 上下文窗口预算
      warn_ratio: float = 0.65           # 65% → 异步预压缩
      compress_ratio: float = 0.80       # 80% → 开始压缩

  预算检查触发压缩层级：

  add_message() → _check_budget()
    ├─ ≥65% (WARN)     → 异步提交压缩计划
    ├─ ≥80% (COMPRESS) → 同步压缩，目标回退到 65%
    ├─ ≥92% (CRITICAL) → 强制压缩，目标回退到 80%
    └─ ≥98% (HARD)     → 紧急压缩

  注意： 这里的 "budget" 使用 Message.token_estimate（len(content) // 4）估算，不是 API 返回的真实 token 计数，也不用于限制总消耗——仅用于触发上下文压缩。
