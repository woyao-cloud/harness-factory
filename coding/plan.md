## Plan

**Goal**: 开发一个完整的 JavaScript 贪吃蛇游戏，包含游戏界面、蛇的移动控制、食物生成、碰撞检测、计分系统和游戏状态管理。

**Context**: 该项目将创建一个单文件 HTML 游戏（包含内联 CSS 和 JS），或者拆分为 HTML、CSS、JS 三个文件。游戏需要支持键盘方向键控制蛇的移动，蛇吃到食物后长度增加并计分，撞墙或撞自身则游戏结束。

### Task: task_1
创建 HTML 结构文件 `index.html`，包含游戏画布（Canvas）、分数显示区域、游戏状态提示（开始/结束/暂停按钮或文字），以及引入外部 CSS 和 JS 文件的链接。
- Depends on: (none)

### Task: task_2
创建 CSS 样式文件 `style.css`，设计游戏整体外观：深色背景、网格风格的画布样式、分数和状态提示的字体与布局、按钮样式、响应式适配等。
- Depends on: task_1

### Task: task_3
创建 JavaScript 游戏核心逻辑文件 `game.js`，实现以下模块：
- 游戏配置常量（网格大小、画布尺寸、初始速度等）
- 蛇的数据结构（坐标数组）与食物坐标
- 游戏状态变量（进行中、暂停、结束）
- 初始化函数（重置蛇、生成随机食物）
- 游戏主循环（requestAnimationFrame 驱动）
- 蛇的移动逻辑（方向更新、坐标计算）
- 食物生成逻辑（随机位置、不与蛇重叠）
- 碰撞检测（墙壁碰撞、自身碰撞）
- 计分系统
- 游戏结束与重置逻辑
- Depends on: task_1

### Task: task_4
实现用户输入控制模块（在 `game.js` 中或单独文件 `controls.js`），处理键盘事件（方向键上下左右），防止蛇反向移动（不能直接掉头），可选支持触屏滑动控制。
- Depends on: task_3

### Task: task_5
实现游戏渲染模块（在 `game.js` 中或单独文件 `renderer.js`），负责在 Canvas 上绘制：
- 网格背景
- 蛇身（不同颜色区分头部和身体）
- 食物（红色或其他显眼颜色）
- 分数和游戏状态文字
- Depends on: task_3

### Task: task_6
编写测试文件 `test.html` 或测试脚本，验证核心功能：
- 蛇的初始化位置正确
- 键盘控制方向有效
- 吃到食物后蛇长度增加、分数更新
- 撞墙和撞自身触发游戏结束
- 游戏重置功能正常
- Depends on: task_4, task_5
